# Machine Learning Projects – Master in Artificial Intelligence

This repository contains a series of practical assignments (TPs) completed as part of the Machine Learning course at the University of Caen Normandy.

---

## TP1 – Regression

**Folder:** `TP1_Regression`

This notebook focuses on supervised learning using regression techniques.  
The goal is to study and compare different regression models (such as linear regression, polynomial regression, etc.) using synthetic and/or real datasets.  
The folder also includes an `environnement.txt` file describing the software environment used for reproducibility.

---

## TP2 – Clustering

**Folder:** `TP2_Clustering`

This practical work introduces unsupervised learning through clustering methods.  
The notebook explores different clustering algorithms, such as K-Means and Hierarchical Clustering, and analyzes their behavior on various datasets using visualization techniques and clustering metrics.

---

## TP3 – Support Vector Machines (SVM)

**Folder:** `TP3_SVM`

This TP focuses on classification using Support Vector Machines.  
The notebook uses a two-dimensional dataset (`data2D.csv`) to illustrate the principles of linear and non-linear SVMs, kernel functions, margin maximization, and decision boundaries.

---

## TP4 – Boosting

**Folder:** `TP4`

This notebook explores boosting algorithms, especially AdaBoost.  
It includes both theoretical explanations and practical implementation of boosting techniques for improving weak classifiers.  
The experiments are conducted on toy datasets to visualize the learning process and error reduction over iterations.

---

## TP – Data Mining

**Folder:** `TP_Data_Mining`

This project is split into two parts:

### Parts 1 & 2 (Folder: `parties-1-2`)
The first part applies the DBSCAN algorithm for density-based clustering on several datasets.  
It includes visualizations of the clustering results (`dbscan1.png`, `dbscan2.png`, `dbscan3.png`) and a script (`parties-1-2.py`) explaining the implementation and parameter selection.  
The notebook (`parties-1-2.ipynb`) provides step-by-step documentation of the experiments and analysis.

### Part 3 (Folder: `partie-3`)
This final part deals with multilingual tag processing.  
The script `partie3.py` reads a JSON file (`traductions.json`) containing tag translations and processes tag lists by cleaning, translating, and filtering them using regular expressions and automatic translation (Google Translate API).  
The task illustrates data preprocessing and normalization in a data mining context.

---

Each TP was completed in Python using Jupyter Notebooks.  
These assignments cover key aspects of both supervised and unsupervised machine learning, and data preprocessing in real-world applications.
